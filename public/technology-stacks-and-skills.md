## Skills Classification Notes

This document combines hands-on experience, active project technologies,
and technologies previously researched or explored. It is not a formal
proficiency assessment.

Before using this inventory in a resume or portfolio, classify each
skill as:

-   **Advanced:** Can independently design, implement, troubleshoot, and
    optimize solutions.
-   **Proficient:** Can confidently use the technology in practical
    projects.
-   **Familiar:** Has studied, tested, or explored the technology but
    has limited practical experience.

In particular, verify proficiency levels for Next.js, Redis, Docker,
Kubernetes, TypeScript, Java, Kotlin, and Python before presenting them
as core skills.
